## 화면 구성

- **상단 커버**: 테마에 맞는 감성 사진 커버(프리셋 12종 / 내 사진 올리기) + 프로필 아바타 + 제목 + 인용구(제목·인용구는 화면에서 바로 수정)
  - 파스텔: 물빛 고양이 · 바다 · CD 케이스 · 코지 캣
  - 크리스마스: 눈 고양이 · 런던의 밤 · 벨벳 트리 · 레드 바이닐 · 눈사람 · 공원 트리 · 엠파이어 · 밤 트리
- **왼쪽 사이드바 (26%)**
  - `NAVIGATION` — **STUDY / 가계부 / 투자 / Wishlist / 메모** 다섯 버튼. 누르면 가운데 큰 팝업(Center Peek)이 열리고, 하위 섹션이 한 화면에 전부 스크롤로 펼쳐집니다.
  - `D-DAY` — STUDY의 "이번 달 시험·지원"과 실시간 연동
  - `TO-DO List` — 빠른 체크리스트
  - `🎯 이달의 목표` — STUDY의 <이달의 목표>와 **같은 데이터로 양방향 연동**. 홈에서 바로 체크·추가·수정(✏️)·삭제할 수 있고, 달성한 목표는 글자에 줄이 그어지며 글자색이 연해지고 목록 맨 아래로 내려갑니다(진행률 바 포함).
  - `🎨 꾸미기 설정`
- **오른쪽 메인 (74%)**
  - 파스텔 하늘색 플립 시계(AM/PM + 12시간제 시·분·초 + 요일) · 오늘 날씨(현 위치 또는 인천, Open-Meteo) · 아치형 cozy cat 카드
    - 날씨 카드를 누르면 **현 위치 기준 10일 예보 팝업**이 열립니다(위치 권한을 거절하거나 못 받으면 인천 기준).
  - 월간 캘린더 — 애플 캘린더에서 옮긴 일정 + 시험·지원 + **수입(+₩) / 지출(−₩) / 예정** 금액이 함께 표시. 날짜를 누르면 상세 보기·추가
    - 캘린더 제목이나 **📅 크게 보기**를 누르면 **큰 상세 캘린더 팝업**: 한 달 전체 달력(월 이동 · 오늘) + 고른 날짜 상세 패널 + **이번 달 전체 일정 아젠다**(일정·시험·D-DAY·예정 지출을 날짜별로 한 번에). 날짜 칸을 누르면 기존처럼 그 날짜 상세 팝업

## 가계부 계산 규칙

- **이번 달 지출** = 실제 지출 + 정기구독·구매예정(그 달 예정 금액). 카드를 누르면 「정기구독」·「구매예정」 카테고리까지 함께 도넛으로 보여줍니다.
- **저축 / 수입 - 지출 - 투자** = 그 달에 기록한 `저축` 유형 합계, 그리고 `수입 − 이번 달 지출 − 저축·투자`.
- **잔액 이월** = 매달 1일에 전달 잔액(`전달 수입 − 전달 지출(예정 포함) − 전달 저축·투자`)을 `잔액` 카테고리로 얹습니다. 저장하지 않고 그때그때 계산하며, 전달에 실제 내역이 있을 때만 이월해서 빈 옛 달로 끝없이 번지지 않습니다.

## 등록한 항목 고치기 (✏️)

일정(캘린더 연동)을 뺀 **모든 등록 항목**은 지우지 않고 바로 고칠 수 있어요. 각 항목 옆 `✏️` 를 누르면 수정 창이 뜹니다.

- 가계부 **수입·지출·저축 내역** — 날짜·종류(지출↔수입↔저축)·내역·금액·카테고리·메모 (종류를 바꾸면 카테고리 목록이 자동으로 바뀌어요)
- **투자** 팝업의 **재무목표 · 주식투자 메모**, 가계부의 **정기구독**
- Wishlist **사고 싶은 것 · 사야 하는 것**
- **한줄일기** — 날짜·기분·내용 · **습관·루틴** — 이름(체크 기록은 그대로) · **메모 카드** — 제목·태그·본문
- STUDY **이달의 목표 · 이주의 목표 · 오늘의 목표** / 홈 **🎯 이달의 목표** / 홈 **TO-DO List**

수정 창은 입력칸 왼쪽 정렬, 날짜 칸은 라벨 + 100% 폭 규칙을 그대로 따릅니다.

- 아이패드 가로 1180 / 세로 834 / 아이폰 390 폭에서 확인했고, 390px에서 가로 스크롤이 생기지 않습니다 (달력은 색 막대 + 금액으로 요약, 날짜를 누르면 상세).
- 터치 기기에서는 버튼·체크박스를 크게(`@media (hover:none), (pointer:coarse)`).

## 저장과 동기화

- 모든 내용은 먼저 **이 기기(localStorage)** 에 저장됩니다. 인터넷이 없어도 그대로 동작해요.
- **동기화 코드**가 같으면 기기끼리 자동으로 맞춰집니다 (아이패드 ↔ 아이폰).
  - 기본 코드는 앱에 들어 있어서 처음 열면 바로 동기화됩니다.
  - `🎨 꾸미기 설정 → 동기화`에서 **새 코드로 바꾸면** 나만의 비밀 코드가 됩니다. (바꾼 뒤 다른 기기에서도 같은 코드를 입력)
- 클라우드에는 **AES-GCM으로 암호화한 내용만** 저장됩니다. 코드를 모르면 읽을 수 없어요.
- 저장 위치: Supabase `trip_dashboards` 테이블의 `gayeon-dash-<코드해시>` 행.
  - 여행 앱 데이터와 같은 테이블을 쓰지만 **행이 완전히 분리**되어 있어 서로 영향을 주지 않습니다.
  - 전용 테이블로 옮기고 싶다면 `supabase-schema.sql`을 Supabase SQL Editor에서 실행하면 준비됩니다.

## 개발

```bash
# 의존성 (jsdom)
npm install

# 테스트
npm test        # tests/smoke.test.js  (DOM 동작 419개)
                # tests/sync.test.js   (암호화 9개)
```

- `index.html` · `styles.css` · `app.js` 세 파일이 전부입니다. 빌드 과정 없음.
- 에셋: `cover-sky-cat.jpg`(기본 커버) · `photo-sea.jpg` · `photo-cd.jpg` · `cover-cozy-cat.jpg`(파스텔 프리셋) · `cat-card.jpg`(고양이 카드) · `profile-avatar.png`(하치와레 프로필) · `xmas-*.jpg`(크리스마스 프리셋 8장 + 썸네일) · `apple-touch-icon.png`(180) · `icon-192.png` · `icon-512.png`
- iOS 홈 화면: `manifest.webmanifest` + `apple-touch-icon`(하치와레)로 추가
- 배포: `gh-pages` 브랜치 루트 → GitHub Pages.

# 🩵 My Dashboard · 가연님 대시보드

아이패드(가로/세로)와 아이폰에 맞춘 파스텔 하늘색 개인 대시보드입니다.
노션 스타일의 2단 레이아웃 + 굿노트 스케치 구성 + cozy cat 감성으로 만들었어요.

**라이브**: https://hobi0905.github.io/gayeon-dashboard/

---

## 화면 구성

- **상단 커버**: 물빛 고양이 커버(사진 교체 가능) + 제목 + 인용구(둘 다 화면에서 바로 수정)
- **왼쪽 사이드바 (26%)**
  - `NAVIGATION` — **STUDY / 가계부 / Wishlist / 메모** 네 버튼. 누르면 가운데 큰 팝업(Center Peek)이 열리고, 하위 섹션이 한 화면에 전부 스크롤로 펼쳐집니다.
  - `D-DAY` — STUDY의 "이번 달 시험·지원"과 실시간 연동
  - `SIMPLE TODO` — 빠른 체크리스트
  - `🎨 꾸미기 설정`
- **오른쪽 메인 (74%)**
  - 플립 시계(시·분·초 + 요일) · 오늘 날씨(인천, Open-Meteo) · cozy cat 카드
  - 월간 캘린더 — 애플 캘린더에서 옮긴 일정 + 시험·지원 + 지출/예정 금액이 함께 표시. 날짜를 누르면 상세 보기·추가

## 팝업 안에서 할 수 있는 것

| 팝업 | 섹션 |
|---|---|
| **STUDY** | 이달의 목표 / 이주의 목표 / 오늘의 목표(진행률) · 이번 달 시험·지원(추가하면 홈 D-DAY·캘린더에 자동 반영) |
| **가계부** | 월별 가계부 캘린더(실제 지출 · 예정 지출 구분, 날짜별 추가/삭제) · 재무목표(진행률 바) · 투자 · 정기구독(결제일 자동 반영) |
| **Wishlist** | 사고 싶은 것 → **사야하는 것**으로 이동 · 사야하는 것 → **구매 예정일·금액 입력 시 가계부 캘린더에 예정 지출로 자동 연동** · 구매 완료 체크(실제 지출로 기록) |
| **메모** | 한줄일기(기분 이모지) · 습관·루틴(오늘 체크 + 주간 달성) · 자유 메모 카드 |
| **꾸미기 설정** | 커버·고양이 사진 교체(자동 리사이즈), 제목·인용구, 동기화 코드, JSON 내보내기/불러오기, 전체 초기화 |

## 저장과 동기화

- 모든 내용은 먼저 **이 기기(localStorage)** 에 저장됩니다. 인터넷이 없어도 그대로 동작해요.
- **동기화 코드**가 같으면 기기끼리 자동으로 맞춰집니다 (아이패드 ↔ 아이폰).
  - 기본 코드는 앱에 들어 있어서 처음 열면 바로 동기화됩니다.
  - `🎨 꾸미기 설정 → 동기화`에서 **새 코드로 바꾸면** 나만의 비밀 코드가 됩니다. (바꾼 뒤 다른 기기에서도 같은 코드를 입력)
- 클라우드에는 **AES-GCM으로 암호화한 내용만** 저장됩니다. 코드를 모르면 읽을 수 없어요.
- 저장 위치: Supabase `trip_dashboards` 테이블의 `gayeon-dash-<코드해시>` 행.
  - 여행 앱 데이터와 같은 테이블을 쓰지만 **행이 완전히 분리**되어 있어 서로 영향을 주지 않습니다.
  - 전용 테이블로 옮기고 싶다면 `supabase-schema.sql`을 Supabase SQL Editor에서 실행하면 준비됩니다.

# 테스트

                # tests/sync.test.js   (암호화 9개)
